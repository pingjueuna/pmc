프로젝트 장애 사건 특별수사

AI 음성인식 서비스가 Release D-5에 Critical 장애로 중단되었습니다.

여러분은 PM보호국 신입수사관입니다.
제한된 증거를 분석하고, 팀 토론과 MS Copilot을 활용해 프로젝트 관리 실패의 원인을 밝혀야 합니다.

Copilot 사용 안내
MS Copilot을 사용할 수 있습니다. 단, Copilot의 답을 그대로 제출하지 말고 증거와 대조하여 PM 판단으로 검증해야 합니다.

운영 시간: R1 10분 → R2 20분 → R3 15분 → R4 15분. 시간이 끝나면 자동 제출·봉인 후 다음 라운드가 열립니다.

데모 모드는 라운드별 시간이 짧아 기능 확인용입니다. 실제 대회에서는 “실제 운영 모드”를 사용하세요.

시험 진행 현황

R1 초기 가설
R2 증거 TOP3
R3 가설 수정
R4 종결 보고

각 라운드는 제출물 중심으로 운영됩니다. 시간이 종료되면 현재 선택 상태가 자동 저장되고 다음 라운드가 열립니다.

Round 1. 사건 접수 / 10분

해야 할 일
사건 요약만 보고 팀의 첫 가설을 세웁니다. 이후 증거를 보며 이 가설을 수정하게 됩니다.
배점: 10점
사건 요약: AI 음성인식 서비스가 Release D-5에 Critical 장애로 중단됨. 초기 보고에는 “외주 API 오류”와 “고객 일정 압박”이 주요 원인으로 기록됨. 공식 Root Cause는 아직 확정되지 않음.

제출물① 수사의 첫 가설

Round 2. 증거 수집 / 20분

해야 할 일
각자 맡은 사건파일을 열람하고, Copilot을 수사 보조관으로 활용한 뒤 팀 토론으로 핵심 증거 TOP3를 고르세요.
배점: 25점 = 증거 열람 10점 + 핵심 증거 TOP3 15점
Copilot 프롬프트 예시
아래 증거를 보고 SW PM 관점에서 Root Cause 후보와 추가 확인할 점을 정리해줘. 책임자 비난이 아니라 변경관리·품질관리·리스크관리 관점으로 분석해줘.

PM A: 일정·고객 단서 수사관

고객: 품질 이슈가 명확하다면 최대 3일까지 일정 조정 가능합니다. 출시 후 장애는 수용 불가.
D-15 API 변경 요청 접수 / D-10 개발 수정 완료 / D-7 Regression 계획 미확정 / D-5 Critical 장애.
운영자 교육은 D-3 예정. 이번 장애 원인 분석과 직접 관련성 낮음.

PM B: 품질·결함 단서 수사관

Priority Critical / Closed / 조치: API 수정 완료 / QA Comment: Regression Test 미실시.
기능 단위 테스트 Pass / 통합 테스트 Not Completed / Regression Test Not Performed / 품질 Gate 조건 미충족.
QA 공식 승인 없음. 주간회의록에는 “개발 완료 기준으로 리스크 종료”라고 기록.

PM C: 변경·리스크 단서 수사관

CR-022 외주 API 응답 구조 변경 / 영향도 분석 미작성 / 테스트 재계획 미확정 / 고객 공지 없음.
R-014 외주 API 변경 Risk / Closed / 종료 근거: 개발 수정 완료 / 잔여 리스크·품질 검증 기준 미기재.
QA: Regression Test 필요. PM: 일정상 어렵습니다. 개발 수정 완료 기준으로 우선 Close합시다.
